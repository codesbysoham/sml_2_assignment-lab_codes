# Module II — Metaheuristic Optimisation and Kernel Methods

This directory contains optimisation experiments together with additional labs on regularised regression and nonlinear dimensionality reduction.

| Experiment | Topic | Key concepts |
|---|---|---|
| 8 | Simulated Annealing | Temperature schedule, probabilistic acceptance, escaping local minima |
| 9 | Genetic Algorithms | Encoding, selection, crossover, mutation, elitism and TSP |
| 10 | Particle Swarm Optimisation | Inertia, cognitive/social terms, particle updates and Rosenbrock |
| 11 | L1, L2 and Elastic Net | Ridge, Lasso, sparsity, shrinkage and regularisation paths |
| 12 | Kernel PCA | RBF kernel, kernel centering, eigendecomposition, circles and moons |
| 13 | Ant Colony Optimisation | Transition probabilities, pheromone update and shortest paths |

The existing SA, GA, PSO and ACO notebooks remain in place. Additional regularisation and Kernel PCA notebooks extend the module.

## Run

Install dependencies from the repository root and run notebooks in JupyterLab. The regularisation and Kernel PCA experiments generate their own synthetic or built-in datasets and do not require BSDS500.
